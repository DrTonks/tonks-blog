# 文章写作扩展

普通 .md 文章和加密文章共用渲染链。无须改用 MDX。

## 图片

```md
![替代描述](./photo.jpg "显示在图下的说明")
![替代描述](./photo.jpg)
```

只有独占一段的图片生成居中图框。title 留空不显示图注；alt 保留为替代描述。保持图片原比例，小图不强行放大。图片加载失败会结束占位动画。

## 脚注

```md
正文[^1]

[^1]: 支持文字和[链接](https://example.com/)的注释。
```

鼠标悬停、键盘聚焦或点击角标打开浮层。聚焦角标后按方向键 ↓ 进入浮层，Tab 可访问链接，Escape 关闭。浮层启用后隐藏文末脚注；JavaScript 不可用时保留文末脚注作为回退。

## 隐藏内容

```md
:spoiler[一小段隐藏文字]

:::spoiler{warning="以下包含结局，是否继续？"}
多段内容也可以放在这里。
:::
```

内容默认以模糊文字呈现，不额外增加提示面板。普通模式支持鼠标悬停、键盘聚焦以及点击固定展开；警告模式点击模糊内容后必须确认。普通模式再次点击内容可以收起；警告模式确认后在本次阅读中保持展开，不会因再次点击正文而重新遮挡。它是阅读遮挡，不是加密：内容仍在页面源码中。真正私密文章应使用已有的文章加密功能。

## 音频

```md
::audio{src="/audio/example.mp3" title="标题"}
```

音频文件放在 public/audio，或使用 https 音频地址。播放器不自动播放，不预下载音频，使用可访问的浏览器播放控件及主题外框。src 不支持文章目录相对路径。

## 站内文章卡片

```md
::post{slug="kaifa02/tonks-home-desktop-system"}
```

slug 是 /posts/ 后面的完整文章路径，不含前后斜线。标题、摘要、封面自动读取，被引用文章不存在或生产环境引用草稿会报告错误。没有封面显示主题占位。

## 阅读布局

全站统一最大外框 78rem（1248px），侧栏保持 17.5rem（280px），文章仅限制正文行宽最大 760px、字号 19.2px、行高 1.75（33.6px）；手机 17px。页面之间切换不会改变外框或侧栏宽度。视口 768～1727px 使用左侧栏目录，1728px 起有足够外侧空间时使用右侧目录；手机保留移动目录入口。
