# 博客样式故障审查（2026-09-09）

## 结论

已在本地原发布 dist 重现严重样式错乱。直接原因是 ImageWrapper.astro 的图片 glob 从 ../../** 改为图片白名单后，切断了项目原先隐式引入的核心 CSS/Stylus 依赖。variables.styl、main.css 等没有显式入口，导致主题变量、卡片、弹窗隐藏状态、正文等基础规则未进入产物。重新启动 dev 也能复现，不能归因于 Apache 或上传损坏。

该 glob 收窄由此次发布前修复 .base 管理文件构建错误引入。保留图片白名单是必要的，但遗漏了同步补齐样式依赖。此前构建成功、HTTP 200 与文件哈希一致仅验证发布完整性，没有证明生产页面视觉正确。此前报告中“复审未发现问题”不代表这次版本可发布，现予更正。用户已自行回退线上，本次未上传或重新部署。

## 本地修复

在 src/layouts/Layout.astro 中显式引入八份核心样式：variables.styl、main.css、markdown.css、markdown-extend.styl、expressive-code.css、scrollbar.css、photoswipe.css、widget-responsive.css。保留原有局部样式与移动端覆盖，不恢复扫描整个 src 的图片 glob。

独立复审核对了依赖覆盖：八个新入口、七个原入口及 main.css 的七个间接入口覆盖当前启用功能所需的 22 份样式。未恢复已关闭的 Twikoo 样式（其中有全局 card-base overflow 副作用）；未启用的文章加密样式仍需在未来启用该功能时由其组件显式引入。

直接以本地 HTTP 静态服务打开完整 pnpm build 的 dist，对照回退后的线上首页；不能以 dev 截图替代生产产物验收。完整构建通过，页面构建 10.20 秒、字体子集 16.22 秒、搜索索引 0.90 秒。

浏览器检查覆盖桌面/手机、亮/暗主题：首页、关于页、含代码块的文章，以及从首页实际点击文章的内部导航。检查主题变量、卡片背景、弹窗默认隐藏/点击打开、横向溢出及本地资源失败。截图等待首次加载层退出后检查正文，防止把加载层截图误作最终页面。
