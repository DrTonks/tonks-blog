# 横幅静态消融

水波纹关闭时，横幅使用预先生成的固定透明度遮罩；上方保持完整，底部柔和消失，并沿水平方向平滑渐隐，无起伏，不再使用颗粒。渐隐带占静态遮罩高度的 50%，采用平滑透明度曲线，直接降低图片透明度。没有彩色雾层、实时噪声、SVG filter、JavaScript 动画或额外 RAF。

## 高度

静态消融和水波纹共用 MainGridLayout.astro 的 --banner-edge-height。保留原有宽度、高度及横屏断点的优先级；以后调整该变量即可让两种效果同步，不再单独使用 22vh 的长渐隐。

| 视口 | 消融与水波纹高度 |
| --- | ---: |
| 桌面 1280×900 | 135px |
| 手机 390×844 | 67.52px |
| 横屏 844×390 | 30px |
| 小屏 360×640 | 60px |
| 平板 768×1024 | 120px |

## 资源与维护

- public/assets/banner-edge-mask.svg：实际发布的静态遮罩，必须随源码提交。
- scripts/generate-banner-edge-mask.mjs：确定性的离线生成脚本，修改样式参数后运行 node scripts/generate-banner-edge-mask.mjs；不在每次 build 或浏览器中执行。
- 遮罩由上方不透明层和底部 SVG 渐变层相加组成，重叠 1px 防止小数像素接缝。SVG 顶部不透明、底部完全透明，亮暗主题共用。整个横幅一起遮罩，以避免移动端文字背景产生硬边。

当前 SVG 原始大小 4,758 B（原生 linearGradient，64 个平滑曲线采样点之间连续插值）；线上传输大小取决于服务器压缩配置。本次发布只更新静态站点文件，没有修改 Apache 配置或 PM2。静态并非零绘制成本，背景轮播/缩放仍需合成；未进行 GPU/帧率对比，不宣称固定性能提升百分比。
