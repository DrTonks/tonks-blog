# 友链头像管理

头像放在 `public/images/friends/`，文件名（不含扩展名）与 `src/data/friends.ts` 的 `name` 完全一致，包括大小写、中文和空格。例如 `Tonks Home.jpg`、`时歌的博客.webp`。

支持 webp、avif、png、jpg、jpeg、gif、svg、ico、bmp，扩展名大小写均可。每个 name 保留一张即可；若重复，按以上格式顺序优先选择，构建会提醒。同格式重复时按文件名排序。

页面优先使用本地文件；没有本地文件时使用 JSON 中原有的 avatar 链接，不必修改该链接。新增或改名后，在该文件夹手动添加或重命名头像。name 应使用可作为文件名的字符（Windows 不允许 `/\:*?"<>|` 等字符）。

`pnpm build` 和 `pnpm ship` 在构建验证完成后提醒缺失头像，不自动下载，也不会因提醒而阻止构建或部署。直接运行 `astro build` 不经过这份提示脚本。

这些是正式站点资源，需要和代码一起提交到 Git。构建会将原文件复制到 dist；不需要服务器额外配置，不依赖后端。远程头像更新不会自动覆盖本地文件，确认需要更新后手动替换即可。

本地 dev 添加或删除文件后刷新友链页；部署版本须重新构建才能更新本地优先的选择。
