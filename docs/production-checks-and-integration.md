## 自动检查（最终保留版本）

不自动启动浏览器。Playwright 依赖已移除，页面视觉由用户人工验收。

博客：pnpm build 和 pnpm ship 都会检查生产 HTML/CSS/JS 本地资源引用、必要入口、Pagefind，以及首页/关于/文章实际关联的关键 CSS。即使孤立 CSS 文件仍存在，只要页面失去引用也会拒绝。生产构建与源码指纹绑定；最终上传包清单与通过检查的文件哈希比较，避免校验后换成其他产物。检查回执只代表静态检查，不代表视觉相同。

主页：pnpm ship 在构建后检查入口、CSS、JS、本地资源引用。SFTP 不再清空活动目录；最多 4 个资源并发上传，临时文件下载一次校验 SHA-256 后原子更名；所有资源成功才切换 HTML，index.html 最后。保留旧 hash 资源。共享表情仍由 Apache 独立目录提供，本次不修改它。

共享模块七份一致。线上表情清单仍有历史 weibo/alu 分组，但前端会过滤；当前启用六组内容与本地一致。没有因此删除云端旧资源。
