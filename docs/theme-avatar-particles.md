# 头像粒子可选开关（2026-09-09）

## 使用行为

导航栏调色盘「显示效果」新增「头像粒子」。受支持桌面默认开启，localStorage 键 avatarParticlesEnabled 为字符串 false 时尊重手动关闭；没有保存值时使用默认开启。关闭时仍按亮暗主题展示不同静态头像，主题切换只使用整页单圆形裁剪；不会初始化 WebGL 或分配粒子资源。

窄屏或无 hover 的粗指针设备禁用：`(max-width: 767px), (hover: none) and (pointer: coarse)`。横屏手机、宽屏纯触摸设备也受限，保存过开启偏好也不初始化 GPU；按钮显示「当前设备不启用」。宽屏精细主指针设备可自行开启。系统要求减少动态效果时禁用并停止相应动画。

桌面偏好开启、浏览器支持 View Transition 且允许动效时，在延迟 1200ms 后的空闲时机准备 WebGL。未准备好、不可用、头像离屏等情形使用静态回退。正常粒子效果使用整页和头像两层裁剪，共享时间、圆心和半径，避免边缘错位；关闭时只保留 root 裁剪。

## 生命周期

关闭、跨入设备限制、减少动态效果或组件卸载时，取消定时/空闲/RAF 回调，作废旧解码代次，释放纹理、缓冲、程序和上下文，替换空 canvas 供重新开启使用。返回桌面且保存的开关为开时可重新准备。跨标签页 storage 设置/移除/清空同步。

取消粒子不会提前释放尚未完成的主题过渡锁；动态 reduced-motion 会 skipTransition 并等待 finished，保留目标主题。初始化和动画回调均避免旧代次覆盖新状态。

## 成本与验证

双层裁剪增加截图、合成和内存工作，共享时钟解决同步，不会把两层成本变成一层。粒子另增加 GPU 绘制和更长的切换窗口。既有本机对比未在正常桌面样本中观察到明显新增卡顿，CPU 压力样本存在更差帧间隔，不能保证低端设备表现。当前按用户要求改为桌面默认开启，移动端继续禁用；手动关闭仍只用单裁剪，不依赖不可靠的“高端设备”自动判断。

16/16 逻辑测试通过；模拟 DOM/WebGL 的测试覆盖设备限制、资源释放与重新开启、存储同步、解码竞态、互斥及动态减少动效。独立交叉复审后的修订再次通过审查。

真实 Edge 验证桌面默认开启且仅一个实际 WebGL 上下文、双裁剪与真实绘制、手动关闭后刷新零 WebGL、刷新保留偏好、关闭释放、桌面与移动边界往返、宽屏纯触摸及 reduced-motion。生产页面桌面和移动调色盘实际展开，尺寸没有超出视口；移动端均为零 GPU 初始化。

## 同外观切换与能力降级

目标解析后的亮暗与当前页面相同时，仅保存 system/light/dark 偏好，不进入截图、粒子或新的过渡锁；回到 system 仍能跟随系统。调色盘完整名称为“头像粒子化主题过渡”。

WebGL 通过实际渲染上下文初始化结果判断，不额外建立探测上下文。初始化失败或上下文丢失后释放资源、更新开关为不可用，并在当前页面会话停止重试；不覆盖保存的用户偏好，刷新可以重新检测。尚未初始化时的开关代表偏好，准备失败后会自动降级。
